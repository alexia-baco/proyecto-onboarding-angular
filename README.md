# Task Manager - Onboarding Project

Bienvenido/a a mi proyecto de gestión de tareas. Este repositorio es el resultado de mi proceso de *onboarding*, donde he desarrollado una aplicación completa *Full-Stack*.

## Tecnologías utilizadas
* **Frontend:** Angular, Tailwind CSS
* **Backend:** Symfony, PHP
* **Base de Datos:** PostgreSQL
* **Infraestructura:** Docker

## Funcionalidades principales
* Sistema de autenticación seguro (Login / Logout).
* Gestión y listado de tareas.
* Panel de administración con opciones avanzadas.
* Diseño UI/UX unificado y *responsive*.
